# PanaviBunga Admin

Dashboard Admin untuk PanaviBunga Store — situs statis (HTML/CSS/JS ES
modules), tanpa build step, memakai Firebase Web SDK v10 via CDN. Menunjuk
ke Firebase project yang sama dengan PanaviBunga Store (`panavibunga-store`).

Dibangun menggunakan struktur **Aliftzy Admin** sebagai referensi, tetapi
project ini terisolasi total — Firebase, deployment, dan kredensialnya
berbeda dari Aliftzy Admin.

**Sebelum deploy, baca [`SETUP-PANAVIBUNGA.md`](./SETUP-PANAVIBUNGA.md)** —
berisi checklist wajib (deploy Firestore Rules dengan email admin yang
benar, alur verifikasi pembayaran manual).
